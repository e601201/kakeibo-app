# Webアプリ＋Supabase＋Vercelで作る

iPhoneとMacの両方から同じデータを使い、本人だけがログインでき、運用費を月500円以内に収める必要がある。そこで、ホーム画面に追加できるWebアプリとし、データとGoogleログインはSupabaseの無料枠、公開はVercelの無料枠に任せることにした。1つのコードでiPhoneとMacの両方に対応でき、11月1日の使い始めに間に合わせやすい。

## Considered Options

- **iPhoneアプリ（Swift）＋iCloud同期**：iPhoneでの使い心地は一番良いが、Xcodeでの開発と配布の手間がかかり、4日では間に合わない。
- **Googleスプレッドシート＋Apps Script**：無料で早く作れるが、スマホでの入力がしにくい。また、カード明細の取り込みや二重登録の候補の判定のような処理を書きにくい。
- **端末の中だけに保存するWebアプリ**：サーバーが不要になるが、iPhoneとMacでデータを共有できない。

## Consequences

- データはSupabase（外部のサービス）に置かれる。リポジトリは公開するため、キーは環境変数に置き、個人のお金の情報はリポジトリに入れない。
- 無料枠の条件が変わった場合は、F-11の書き出しでデータを取り出して移せるようにしておく。
