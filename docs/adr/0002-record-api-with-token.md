# 画面を開かずに記録するAPIは、APIトークンで確かめ、その都度本人のセッションを作って書き込む

Claude Code などから curl で記録したい。画面はGoogleログインの cookie で本人を確かめているため、外からは使えない。そこで、自分用のAPIトークン（`KAKEIBO_API_TOKEN`）を確かめる Route Handler を足すことにした。書き込むときは、Supabase の秘密の鍵（`SUPABASE_SECRET_KEY`）で本人（`ALLOWED_EMAIL`）のログイン用リンクを作り、それをその場で使って本人のセッションを作る。こうすると、Row Level Security と今のデータの読み書きのコードをそのまま使える。セッションは使い終わったら消す。

## Considered Options

- **秘密の鍵でそのままテーブルに書く**：一番簡単だが、Row Level Security を素通りする。持ち主を自分で付け、読むときも絞る必要があり、データの読み書きのコードを書き換えることになる。
- **Supabase の REST API に直接書く**：家計簿コアの確かめを通らなくなる。
- **リポジトリ内のコマンドで書く**：インターネットに入口は増えないが、このリポジトリを開いた Claude Code からしか使えない。

## Consequences

- 秘密の鍵をVercelの環境変数に置く。鍵はログイン用リンクを作るためだけに使い、データの読み書きには使わない。
- APIトークンが漏れると記録を書き込まれるので、漏れたら `KAKEIBO_API_TOKEN` を変えて再デプロイする。
- 呼ぶたびにセッションを作るので、1回の記録が画面より少し遅い。
