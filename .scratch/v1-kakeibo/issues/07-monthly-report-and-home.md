# 07: 月次レポートとホーム

**What to build:** 本人が月を選んで月次レポートを開くと、費目ごとの予算・実績・残り・消化率（予算オーバーは赤）、収入の実績と予定額、支出合計・振替合計・未使用・貯蓄率が見られる。ホームには今月の支出合計・残り予算・予算オーバーの費目・要確認の件数が出て、入力・一覧・月次レポート・年間推移・設定に1タップで移れる（F-05）。家計簿コアの「月次レポート」をここで作る。これで第1版が揃う。仕様は `.scratch/v1-kakeibo/spec.md` を参照。

**Blocked by:** 03, 04, 05

**Status:** ready-for-agent

- [ ] 費目ごとに予算（その月に適用されていた値）・実績（返金を差し引いた合計）・残り・消化率が出て、予算オーバーは赤
- [ ] 予算0の費目は消化率を「—」とし、実績が0より大きければ予算オーバー
- [ ] 非表示の費目も、その月に実績か予算があれば行が出る
- [ ] 収入は種類ごとに実績と予定額が並び、記録がなければ実績0円
- [ ] 支出合計・振替合計・未使用（収入の実績−支出合計−振替合計）・貯蓄率（振替合計÷収入の実績）が出る。収入の実績が0以下なら貯蓄率は「—」
- [ ] ホームに今月の支出合計・残り予算（支出の費目の予算合計−支出合計）・予算オーバーの費目・要確認の件数が出る
- [ ] ホームから各画面に1タップで移れる（年間推移は第1.1版までは準備中の表示でよい）
- [ ] 月次レポートのテストがある（返金、予算0の費目、予算オーバー、非表示の費目、収入の記録がない月、未使用と貯蓄率、過去の月は当時の予算）
- [ ] 10年分（約18,000件）の記録があっても、画面表示とレポートが2秒以内に出る
