**What to build:** 本人が年間推移の画面で開始月を選ぶと、12か月分の費目別の実績を表とグラフで見られる。費目ごとの12か月の合計と月平均も出る。支出の費目と振替の費目は分けて見られる（F-07、第1.1版）。家計簿コアの「年間推移」をここで作る。仕様は `.scratch/v1-kakeibo/spec.md` を参照。

- [x] 費目ごとの12か月の合計と月平均が出る。月平均の分母は、支出か振替の記録が1件以上ある月の数（全体で数える）。記録のある月が0なら月平均は出さない
- [x] 支出の費目と振替の費目が区別されている
- [x] ホームから年間推移に移れる

## Comments

- 2026-10-31 実装：家計簿コア（`src/core/trend.ts`：年間推移 `yearlyTrend` と期間 `trendPeriod`）とそのテスト、年間推移の画面 `/trend`、ホームからの入口を追加した。グラフのライブラリとして Recharts（無料）を入れた。マイグレーションはない。
  - 費目が16個あり色で見分けられる数を超えるので、グラフは費目ごとの小さな棒グラフを並べる形にした（支出は青、振替は緑がかった青）。同じ数字を表でも出す。
  - 月平均は12か月の合計を記録のある月の数で割り、円未満を四捨五入する。その費目だけ記録がない場合は0円と出す。
  - 非表示の費目は、12か月の間に記録があるときだけ行を出す（月次レポートと同じ）。
  - 12か月分の記録は Supabase の1回あたりの上限（1000行）を超えうるので、分けて読む。
  - 開始月は前後の月への移動と、月を直接選ぶ欄で選べる。選ばなければ2026年11月から。
  - グラフの見た目は、ログインが要るためまだ画面で確かめていない。
- 2026-10-31 公開したうえで、本人の確認を経てチケット完了。
