# 09: 年間推移

**What to build:** 本人が年間推移の画面で開始月を選ぶと、12か月分の費目別の実績を表とグラフで見られる。費目ごとの12か月の合計と月平均も出る。支出の費目と振替の費目は分けて見られる（F-07、第1.1版）。家計簿コアの「年間推移」をここで作る。仕様は `.scratch/v1-kakeibo/spec.md` を参照。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 開始月を選べ、初期値は2026年11月
- [ ] 費目×月の実績の表と、費目別の実績のグラフ（無料のライブラリ）が出る
- [ ] 費目ごとの12か月の合計と月平均が出る。月平均の分母は、支出か振替の記録が1件以上ある月の数（全体で数える）。記録のある月が0なら月平均は出さない
- [ ] 支出の費目と振替の費目が区別されている
- [ ] ホームから年間推移に移れる
- [ ] 年間推移のテストがある（月平均の分母、記録のない月、12か月の範囲）
