# 03: 支出・振替の入力

**What to build:** 本人がスマホの入力画面で、日付（初期値は今日）・費目・金額を入れて支出を記録できる。内容・支払方法・メモは任意。振替の費目（貯蓄・投資）を選ぶと振替として記録される。マイナスの金額で返金を記録できる。保存後は同じ画面で続けて入力できる（F-03）。家計簿コアの「記録の検証」（支出・振替）をここで作る。仕様は `.scratch/v1-kakeibo/spec.md` を参照。

**Blocked by:** 02

**Status:** done

- [x] 支払方法の初期値（現金、クレジットカード（三井住友カード）、クレジットカード（エポスカード）、電子マネー（PayPay）、電子マネー（Suica）、口座振替、その他）が入っている
- [x] 入力画面で費目を大きなボタンで選べ、非表示の費目は出ない。金額は数字のキーボードで入力できる
- [x] 日付・費目・金額だけで保存でき、保存後は同じ画面で次の記録を入力できる
- [x] 記録が支出か振替かは費目の種類で決まり、記録そのものには種類を持たない
- [x] 家計簿コアの記録の検証：日付・費目・金額が必須、金額は0以外の整数（マイナスは返金として許す）、非表示の費目は新しい記録に使えない。どの項目が間違っているかを返す
- [x] 記録の検証のテストがある（必須項目、金額0・小数・マイナス、非表示の費目）
- [x] 支出・振替のテーブルに、要確認フラグ・登録元（手入力／明細取込）・取込元の明細IDの項目があり、第1版では手入力・要確認なし・明細IDなしで保存される
