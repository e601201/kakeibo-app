# 06: 一覧・修正・削除

**What to build:** 本人が月を選んで、その月の支出・振替・収入を日付の新しい順に一覧で見られる。費目・支払方法・要確認で絞り込み、内容の言葉で検索できる。1件を開いて修正・削除（確認つき）でき、複数の支出・振替を選んでまとめて費目を変えられる（F-04）。家計簿コアの「一覧の絞り込み」をここで作る。仕様は `.scratch/v1-kakeibo/spec.md` を参照。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 月を選ぶと、その月の支出・振替・収入が日付の新しい順で並ぶ
- [ ] 費目・支払方法・要確認・内容の検索語で絞り込める（検索は部分一致で、全角・半角と大文字・小文字の違いは同じものとして扱う）
- [ ] 1件を開いて修正でき、日付を別の月に直すとその月の一覧に移る。既存の記録は、元の費目が非表示になっていてもその費目のまま保存できる
- [ ] 削除する前に確認があり、確認すると消える
- [ ] 複数の支出・振替を選んでまとめて費目を変えられ、変えた記録の要確認の印が外れる
- [ ] 一覧の絞り込みのテストがある（各条件の組み合わせ、全角・半角の違う検索語、日付の新しい順）
