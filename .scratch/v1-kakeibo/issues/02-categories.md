# 02: 費目の管理

**What to build:** 本人が初めてログインすると15個の費目（家賃、食費（食材）、外食、水道光熱費、通信費、日用品、交通費、保険、医療費、被服、美容、交際費、趣味・娯楽、妻へのお小遣い、特別費、貯蓄・投資）が入っている。貯蓄・投資の種類は振替、ほかは支出。設定画面で費目を追加（種類を選ぶ）・名前変更・並べ替え・非表示・表示に戻す・メモができる（F-02）。仕様は `.scratch/v1-kakeibo/spec.md` を参照。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 初回ログイン時に15個の費目が上の順で入っており、貯蓄・投資だけが振替
- [ ] 費目を追加するときに種類（支出／振替）を選べ、作った後は種類を変えられない
- [ ] 費目の名前変更・並べ替え・メモの編集ができ、再読み込みしても残っている
- [ ] 費目を非表示にでき、また表示に戻せる
