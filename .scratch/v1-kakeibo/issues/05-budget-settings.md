# 05: 予算と収入の予定の設定

**What to build:** 本人が設定画面で、費目ごとの月の予算と、収入の種類ごとの月の予定額を、適用開始月を選んで登録・変更できる。予算合計（支出と振替の費目）と収入の予定額の合計の差額が表示される。変更はその月以降にだけ適用され、過去の月の値は変わらない（F-01）。家計簿コアの「予算の適用・変更・差額」をここで作る。仕様は `.scratch/v1-kakeibo/spec.md` を参照。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 設定画面で月を選び、その月に適用される費目ごとの予算と収入の予定額が見られ、変更できる
- [ ] 予算合計と収入の予定額の差額が表示される
- [ ] 家計簿コアの予算の適用：その月以前で最も新しい適用開始月の値を使い、適用開始月がまだ来ていない費目は0円。収入の予定も同じ決まり
- [ ] 家計簿コアの予算の変更：同じ費目・同じ適用開始月の履歴は上書きし、同じ月に複数の値を持たない
- [ ] 予算の適用・変更・差額のテストがある（適用開始月の前後、同じ月の上書き、まだ適用開始月が来ていない費目）
- [ ] 予算の金額の初期値はリポジトリに入れず、本人が設定画面から入力する
