# 05: 予算と収入の予定の設定

## Comments

- 2026-10-31 実装：家計簿コア（`src/core/budgets.ts`：予算の適用 `planForMonth`、予算の変更 `changesForMonth`、予算の差額 `planDifference`。予算と収入の予定は同じ決まりで扱う）とそのテスト、予算と収入の予定のテーブル（`supabase/migrations/20261031000000_budgets.sql`）、設定画面 `/settings/budgets` を追加した。金額の読み取りは `src/core/amount.ts` に切り出し、記録の検証と共通にした。
  - 設定画面で月を選び、額を変えた欄だけを、その月を適用開始月として保存する。空の欄は0円。
  - 同じ月の上書きは、テーブルの一意制約（費目・適用開始月の組）と upsert で守る。家計簿コアは「その月を適用開始月とする変更」を作るところまでを持つ。
  - 後の月にすでに別の値があると、変更はその手前の月までにだけ効く（仕様の「その月以降にだけ適用」のとおり）。
  - 過去の月も選んで直せる。その月以降のレポートの予算も変わるので、過去の月を選ぶと注意を出す。
  - 非表示の費目も予算の行に出し、予算合計に含める。
  - マイグレーションは手元の使い捨てPostgreSQLで確かめた。本番には未適用なので、本人が `supabase db push` で当ててから、設定画面で2026年11月からの予算と収入の予定を入れて確かめる。
