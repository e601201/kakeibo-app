# 10: CSVの書き出し

**What to build:** 本人が設定画面から、支出・振替・収入と、予算・収入の予定の履歴（適用開始月を含む）をCSVでダウンロードできる。MacのExcelやNumbersで文字化けせずに開ける（F-11、第1.1版）。家計簿コアの「CSVの書き出し」をここで作る。仕様は `.scratch/v1-kakeibo/spec.md` を参照。

**Blocked by:** 04, 05

**Status:** done

- [x] 設定画面から、記録（支出・振替・収入）のCSVと、予算・収入の予定の履歴のCSVをダウンロードできる
- [x] 費目名・支払方法名は名前で書き出される
- [x] CSVはUTF-8（BOM付き）で、Numbersで開いても文字化けしない
- [x] CSVの書き出しのテストがある（BOM、カンマや改行を含む内容、マイナスの金額）

## Comments

- 2026-10-31 実装：家計簿コア（`src/core/csv.ts`：記録のCSV `recordsCsv` と予算・収入の予定の履歴のCSV `plansCsv`）とそのテスト、書き出しの道 `/export/records`・`/export/plans`、設定画面の書き出しの欄を追加した。マイグレーションはない。
  - CSVは UTF-8（BOM付き）、改行は CRLF。カンマ・改行・ダブルクォートを含む値はダブルクォートで囲む。
  - 記録のCSVは支出・振替・収入を1つのファイルに、日付の古い順で書く。予算のCSVには費目の種類（支出／振替）も書く。
  - 全期間を読むので、Supabase の1回あたりの上限（1000行）を超えても読めるよう、分けて読む共通の関数（`src/lib/data/pages.ts`）を作り、既存の読み込みもそれに揃えた。
  - ログインが切れていたときにログイン画面がCSVとして保存されないよう、リンクに download は付けず、応答のヘッダーでファイルとして保存させる。
  - 書き出していないもの：費目の種類・メモ・非表示・表示順、支払方法の一覧、生活防衛資金の設定、記録の登録元・取込元の明細ID。別の仕組みに移すときに要るなら、別のチケットで足す（登録元と明細IDは第2版の取り込みの前に）。
  - 内容・メモが = + - @ で始まると、Excel が数式として読むことがある。データをそのまま残すため、書き換えはしていない。
- 2026-10-31 公開したうえで、本人の確認を経てチケット完了。
