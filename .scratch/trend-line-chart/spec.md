# 年間推移を折れ線グラフにする

Status: ready-for-agent

元にした文書：`.scratch/v1-kakeibo/spec.md` の年間推移（F-07、ストーリー72〜77）、`GLOSSARY.md`

## Problem Statement

年間推移のグラフは、費目ごとの小さな棒グラフを並べる形になっている。費目どうしの増え方を比べるには、カードを行き来して目で見比べるしかない。気になる費目だけを並べて見ることもできない。

また、開始月を選ばなければ使い始めた月（2026年11月）から12か月が出る。そのため、ここ数か月の動きを見るには毎回開始月を選び直す必要がある。

## Solution

支出と振替のそれぞれで、費目を1枚の折れ線グラフに重ねて出す。グラフの下にある費目のチェックボックスで、線の表示と非表示を切り替えられる。開始月を選ばなかったときは、今月の3か月前から12か月を出す。

## User Stories

1. 本人として、支出の費目を1枚の折れ線グラフに重ねて見たい。費目どうしの増え方を見比べるため
2. 本人として、振替の費目は支出とは別の折れ線グラフで見たい。貯蓄・投資を支出と混ぜず、金額の桁の違いで線がつぶれないようにするため
3. 本人として、グラフの下の費目のチェックボックスで、線の表示と非表示を切り替えたい。気になる費目だけを並べて見るため
4. 本人として、「すべて選ぶ」「すべて外す」でまとめて切り替えたい。15個近い費目を1つずつ押さなくて済むようにするため
5. 本人として、選んだ費目をこの端末に覚えておいてほしい。開始月を変えても、ページを開き直しても、選び直さなくて済むようにするため
6. 本人として、チェックボックスの色の印で、どの線がどの費目かわかるようにしたい。凡例を別に探さなくて済むようにするため
7. 本人として、ある月を押すと、表示中の費目の金額を大きい順に見たい。その月に何が多かったかがすぐわかるようにするため
8. 本人として、まだ来ていない月には線を描かないでほしい。来月以降が0円に落ちて、減ったように見えないようにするため
9. 本人として、開始月を選ばなければ今月の3か月前から12か月を見たい。直近の動きを毎回選び直さずに見るため

## Implementation Decisions

- **グラフ**：費目ごとの小さな棒グラフをやめる。支出の費目を重ねた折れ線グラフ1枚と、振替の費目を重ねた折れ線グラフ1枚にする。グラフのライブラリは今と同じ Recharts を使う
- **表**：費目×12か月の表（合計・月平均つき）は今のまま残す。費目ごとの合計と月平均は表にだけ出し、グラフのまわりには出さない
- **線を描く範囲**：横軸には12か月すべてを並べる。線は今月（日本時間）まで描き、その費目の記録がない月は0円として描く。来月以降は描かない
- **色**：費目の並び順に8色を割り当てる。9個目の費目からは同じ8色を点線で使う。色は dataviz の参照パレットから選ぶ
- **吹き出し**：ある月を押すと、その月の表示中の費目と金額を、金額の大きい順に並べて出す
- **チェックボックス**：
  - グラフごとに、そのグラフのすぐ下に費目のチェックボックスを並べる。各チェックボックスには線と同じ色・線の種類の印を付け、凡例を兼ねる
  - 振替の費目が1つでもチェックボックスを出す
  - 「すべて選ぶ」「すべて外す」のボタンを置く
  - 出す費目は表と同じにする。非表示の費目も、12か月の間に記録があれば出す
- **選んだ状態の保存**：この端末（ブラウザ）に、外した費目を費目の id で覚える。開始月を変えても、ページを開き直しても残す。初めて開いたときと、あとから追加した費目は、最初はオンになる
- **開始月の初期値**：開始月を選ばなかったときは、今月（日本時間）から3を引いた月にする（2026年11月なら2026年8月で、表示は2026年8月〜2027年7月）。12か月を並べることと、前後の月への移動・月を直接選ぶ欄は今のまま
- **家計簿コア**：「今日の日付から開始月の初期値を出す」決まりを `src/core/trend.ts` に加え、テストもそこで書く。年間推移の集計（`yearlyTrend`）の結果は変えない

## Testing Decisions

- 家計簿コア：開始月の初期値のテスト（年をまたぐ場合。たとえば2027年1月なら2026年10月）
- 線を描く範囲・色の割り当て・保存は画面の決まりなので、家計簿コアのテストには入れない。画面で確かめる

## Out of Scope

- 表の見た目の変更
- 年間推移の集計の中身（実績・合計・月平均の出し方）の変更
- 選んだ費目を端末をまたいで共有すること（Mac と iPhone で別々に覚える）
