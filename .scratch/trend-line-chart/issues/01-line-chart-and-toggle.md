# 01: 年間推移を折れ線グラフにし、費目を選んで重ねる

**What to build:** 本人が年間推移の画面を開くと、支出の費目を重ねた折れ線グラフと、振替の費目を重ねた折れ線グラフが出る。グラフの下の費目のチェックボックスで線の表示と非表示を切り替えられ、選んだ状態はこの端末に残る。開始月を選ばなければ、今月の3か月前から12か月が出る。仕様は `.scratch/trend-line-chart/spec.md` を参照。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 費目ごとの小さな棒グラフがなくなり、支出の折れ線グラフ1枚と振替の折れ線グラフ1枚が出る
- [ ] 線は今月まで描かれ、記録のない月は0円、来月以降は描かれない。横軸は12か月すべて並ぶ
- [ ] 色は並び順に8色で、9個目の費目からは点線になる
- [ ] ある月を押すと、表示中の費目と金額が大きい順に吹き出しで出る
- [ ] 各グラフの下に、色の印つきの費目のチェックボックスと「すべて選ぶ」「すべて外す」がある。振替の費目が1つでも出る
- [ ] 非表示の費目も、12か月の間に記録があればチェックボックスが出る
- [ ] 選んだ状態がこの端末に残り、開始月を変えても開き直しても保たれる。新しい費目は最初オン
- [ ] 開始月を選ばなければ今月の3か月前から12か月が出る。前後の月への移動と月を直接選ぶ欄は今のまま
- [ ] 表（合計・月平均つき）は今のまま
- [ ] 家計簿コアに開始月の初期値の決まりとテストがある（年をまたぐ場合を含む）
