# 01: 年間推移を折れ線グラフにし、費目を選んで重ねる

**What to build:** 本人が年間推移の画面を開くと、支出の費目を重ねた折れ線グラフと、振替の費目を重ねた折れ線グラフが出る。グラフの下の費目のチェックボックスで線の表示と非表示を切り替えられ、選んだ状態はこの端末に残る。開始月を選ばなければ、今月の3か月前から12か月が出る。仕様は `.scratch/trend-line-chart/spec.md` を参照。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] 費目ごとの小さな棒グラフがなくなり、支出の折れ線グラフ1枚と振替の折れ線グラフ1枚が出る
- [x] 線は今月まで描かれ、記録のない月は0円、来月以降は描かれない。横軸は12か月すべて並ぶ
- [x] 色は並び順に8色で、9個目の費目からは点線になる
- [x] ある月を押すと、表示中の費目と金額が大きい順に吹き出しで出る
- [x] 各グラフの下に、色の印つきの費目のチェックボックスと「すべて選ぶ」「すべて外す」がある。振替の費目が1つでも出る
- [x] 非表示の費目も、12か月の間に記録があればチェックボックスが出る
- [x] 選んだ状態がこの端末に残り、開始月を変えても開き直しても保たれる。新しい費目は最初オン
- [x] 開始月を選ばなければ今月の3か月前から12か月が出る。前後の月への移動と月を直接選ぶ欄は今のまま
- [x] 表（合計・月平均つき）は今のまま
- [x] 家計簿コアに開始月の初期値の決まりとテストがある（年をまたぐ場合を含む）

## Comments

- 2026-11-02 実装：家計簿コアに開始月の初期値 `defaultTrendStart`（`src/core/trend.ts`）とテストを加え、年間推移の画面の初期値を差し替えた。グラフは `src/app/trend/trend-charts.tsx` の `TrendLineChart` に置き換えた。マイグレーションはない。
  - 外した費目の id をブラウザの localStorage（`kakeibo:trend:hidden-categories`）に覚える。支出と振替のグラフで同じ記録を使う。覚えられない環境では、ページを開いている間だけ覚える。
  - 吹き出しは Recharts の `itemSorter` で金額の大きい順にした。グラフを押したときに出るフォーカスの枠は消した。
  - ログインが要るため本番のデータでは見ていない。作り物のデータ（支出15費目・振替1費目）を一時的なページに出し、スマホ幅で表示・切り替え・吹き出し・開き直したあとの保持を確かめた（一時的なページは消した）。
  - 公開後に本人が画面で確かめたら done にする。
